🖱️ GA4 自定义事件 GA4

使用 gtag('event', ...) 发送带参数的自定义事件。

gtag('event', 'signup_click', { 'method': 'email', 'plan': 'free' });

🛒 Meta 标准事件 Meta

使用 fbq('track', ...) 发送 Meta 预定义的标准事件。

fbq('track', 'AddToCart', { content_ids: ['SKU_001'], content_name: '测试商品', value: 99.00, currency: 'USD' });

📦 GTM 自定义事件 GTM

使用 dataLayer.push() 发送自定义事件。 这个事件不会自动发送到 GA4，需要先在 GTM 中创建对应的 触发器（Custom Event） 和 GA4 事件标签。

window.dataLayer = window.dataLayer || []; dataLayer.push({ 'event': 'cta_click', 'cta_location': 'hero_section', 'conversionValue': 25 });

💡 在 GTM 预览模式中可以看到 cta_click 事件被触发，但如果没有配置对应标签，数据不会进入 GA4。
